Nexus lives at `/nexus`. Your foundation model answers by default; the ability buttons pin a job
to the engine that can actually do it.

## Composer controls

| Control | What it does |
| --- | --- |
| Model | Selects the answering model. Default `josephdougherty483/qai2`. |
| ◆ DEEP | Multi-model synthesis, or an Argon offload. |
| ◉ VOICE | Speaks replies aloud. |
| 🎤 MIC | Voice conversation in, spoken replies out. |
| ◈ FACE | Opens the video PAL inside the screen, no navigation. |
| ⚙ ARGON | Stores your Argon key for Deep mode. |

## Endpoint

<CodeGroup>
```bash cURL
curl -s https://quantumnexus-josephdougherty483-7465s-projects.vercel.app/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"hello"}'
```
</CodeGroup>

Backups engage only when QAI2 is genuinely down, never during warm-up. Order: Modal, then the
Cloudflare worker, then the Colab notebook, then the in-app backup. A cold start is not an outage:
there is a 35 second probe, two real failures and a two minute cooldown.
