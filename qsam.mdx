## Live endpoints

| Endpoint | Purpose |
| --- | --- |
| `https://qsam-qchain.onrender.com/api/status` | Height, blocks, transactions, supply |
| `https://qsam-qchain.onrender.com/api/verify` | Block validation with errors |
| `https://mastercyril.github.io/qchain-explorer/` | Public explorer |
| `https://13thchamberllc.com/1000-qsam-airdrop/` | The airdrop page |

The node is on a free tier and sleeps when idle, so the first call can take up to a minute to wake.
That is a cold start, not an outage.

## The airdrop

Every registered wallet receives 1,000 QSAM from the chain treasury, as a signed transaction on
our own chain rather than a transfer on Solana. One credit per wallet, and the treasury log is
public.
