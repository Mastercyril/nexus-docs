Typed slash commands work even with Deep mode off:

| Command | Job |
| --- | --- |
| `/img` | Draw the prompt. Produces the picture, not a description. |
| `/vid` | Generate video. |
| `/fable`, `/story` | Narrative writing. |
| `/code` | Code, including Unity C#. |
| `/math` | Arithmetic and reasoning. |
| `/memory` | Reads and writes the memory bank. |

## Memory bank

A private bank per person, owned by a user code, never mixed with QAI2 records. It lives at
`https://13thchamberllc.com/memory-bank/`.
